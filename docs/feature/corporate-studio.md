# 企业宣传片制作工作台

为市场、产品及招聘团队制作图文宣传片。项目从品牌形象、产品推介、团队招募模板或空白分镜开始。

| 环节 | 用户操作与结果 |
| --- | --- |
| 策划 | 填写项目名、企业名、影片标题，选择横屏或竖屏、品牌色，并可填写片尾行动文案。 |
| 分镜 | 替换图片、编辑字幕和 1–30 秒时长，添加、删除或前后移动镜头，保留至少一镜。 |
| 预览 | 时间轴随分镜顺序和时长更新。可检查单镜或整片，企业名贯穿全片，标题在首镜、行动文案在末镜出现。 |
| 保存 | 手动保存到当前设备、浏览器和站点的草稿库，可再次打开编辑或删除。 |
| 导出 | 前台录制画布，横屏 1280×720、竖屏 720×1280。使用浏览器支持的 MP4 或 WebM 编码，生成无声视频。 |

分镜交互参考 `bgssai-short` 的镜头卡、稳定镜头 ID、排序、时长汇总和逐镜预览。模板文案以企业、产品或团队为主，鼓励用实拍照片和真实品牌文案替换示例。

[默认工作台画面](../demo-static/web/user/workbench.webp)。三张内置示例图由 ImageGen 生成，分别呈现夕阳下的设计园区、调整精密仪器的工程师、讨论产品原型的团队。模板中的企业名称和品牌文案为示例。

## 数据与接口

`GET /api/templates` 返回公开模板数组。每个模板包含 `id`、`name`、`company`、`title`、`aspect`、`brandColor`、`closingLine` 和有序的 `scenes`。分镜包含 `id`、`caption`、整数秒 `duration` 和图片路径 `image`。从模板新建时分配新的项目与分镜 ID。用户替换的图片在浏览器内解码并写入草稿。

浏览器数据库 `bgssai-corporate-studio` 版本 1 的 `drafts` 对象仓以项目 ID 为主键，记录 `project` 与保存时间 `updatedAt`。服务器提供模板、示例图、前端资源及就绪检查。清理站点数据会清除草稿。
